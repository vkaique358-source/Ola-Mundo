**Como executar o jogo de corrida (Windows / PowerShell)**
- Instale as dependências:

```powershell
python -m pip install -r requirements.txt
```

- Execute o jogo (arquivo em `jogo  corrida python`):

```powershell
python "jogo  corrida python\jogo_corrida.py"
```

Use as setas esquerda/direita para mover o carro. Após colisão, pressione `R` para reiniciar ou `Q`/`Esc` para sair.
